# SEO for Smart21network (website at https://smart21network.smart21brain.com)

## What is already built in
* **Page tags:** keyword title and description, canonical address, robots tag, English + Kiswahili (`hreflang`) links, Open Graph and Twitter share cards with a 1200x630 image.
* **Structured data (JSON-LD):** Organization, WebSite and SoftwareApplication on the home page; WebPage, Breadcrumb and FAQ on every guide. No fake ratings are used.
* **11 landing pages**, each with its own title, one H1, real content, FAQ and links to the others: network simulator, MikroTik simulator, CCNA lab practice, VLAN lab, OSPF lab, NAT/ACL/firewall lab, Wi-Fi simulator, Packet Tracer alternative, for schools, AI assistant, and a Kiswahili page (`/sw/`).
* `sitemap.xml`, `robots.txt`, `404.html` (with noindex), favicon, `_headers` (cache + security headers), and a `<noscript>` text version of the home page for crawlers that do not run JavaScript.

All of it is generated by `npm run web:prep`, which the GitHub deploy already runs.
Check it any time with: `npm run web:prep && npm run seo:check`

## To change the text of a guide
Edit `scripts/seo-pages.js` (titles up to 60 characters, descriptions 70-160), upload it, and run **Actions -> Deploy website + AI to Cloudflare**.

## After the deploy: tell Google and Bing (about 10 minutes)
1. Open `https://smart21network.smart21brain.com/robots.txt` and `/sitemap.xml` in a browser. Both must load.
2. Go to https://search.google.com/search-console and add a **Domain** property for `smart21brain.com`. Choose the DNS TXT method and add the TXT record in Cloudflare -> your domain -> DNS. This covers the whole smart21brain.com including smart21network.
3. In Search Console: **Sitemaps** -> enter `https://smart21network.smart21brain.com/sitemap.xml` -> Submit.
4. **URL inspection** -> paste the home page address and each guide address -> **Request indexing**.
5. Bing Webmaster Tools (bing.com/webmasters): sign in and **Import from Google Search Console**.
6. Test: Google Rich Results Test (search.google.com/test/rich-results) and PageSpeed Insights for the home page and one guide.

## What helps most from now on
* **Links from your own sites:** add a clearly visible link to `https://smart21network.smart21brain.com/` on smart21brain.com (menu and footer), on the ElectroLab site, in your GitHub project README and on your social pages. Use the words "network simulator" in the link text.
* **More helpful guides:** one page per question people search (for example "how to configure inter-VLAN routing", "RIP vs OSPF"). Add them to `scripts/seo-pages.js`.
* **Share it:** teachers, WhatsApp groups, school pages and YouTube videos that link to the simulator.
* **Keep it fast and working:** the app is large, so keep the Cloudflare deploy up to date.

## Honest expectations
Nobody can promise a number one place on Google. New pages are usually found within days and need weeks or months to climb. These steps make sure Google can read, understand and trust the site.
